# Catatan Penggunaan AI

| Tugas | Yang diminta ke AI | Kesalahan/kekurangan hasil AI | Cara membuktikan |
| --- | --- | --- | --- |
| Tugas 2 — Penjelajah Node (`jelajah.py`) | Meminta referensi lokasi Syntax Tree Playground di dokumentasi Tree-sitter untuk memverifikasi hasil traversal `jelajah.py`, serta pembuatan kode penjelajah pohon rekursif dengan posisi dan label field. | AI memberikan alamat URL playground yang salah (`https://tree-sitter.github.io/tree-sitter/playground`) sehingga menghasilkan halaman *404 Document not found*. Selain itu, hasil traversal `jelajah.py` mencetak nomor baris 1-based (`baris + 1`) sementara Playground menggunakan 0-based, yang tidak dijelaskan di awal oleh AI. | Membuka URL tersebut secara langsung di browser dan mendapati pesan *Document not found (404)*, lalu menelusuri situs dokumentasi hingga menemukan URL yang benar (`.../7-playground`) dan membandingkan koordinat 55 baris output `contoh.py` antara `jelajah.py` dan Playground. |
| Tugas 4 — Grammar DSL Filter (`tree-sitter-filter`) | Meminta panduan langkah bertahap pembuatan `grammar.js` (4a–4g) untuk bahasa filter beserta penanganan operator logika (`and`, `or`, `not`), `in`, `contains`, dan kasus pengujian `test/corpus/`. | AI sempat menempatkan kemunculan konflik ambiguitas *unresolved conflict* pada langkah 4c (saat menambahkan `or_expression`), padahal konflik sebenarnya sudah muncul lebih awal pada langkah 4b (saat menambahkan `and_expression` tanpa `prec.left`). AI juga sempat menyarankan penggunaan `tree-sitter test` dengan menyertakan koordinat baris/kolom pada pohon ekspektasi di panduan awal. | Menjalankan `tree-sitter generate` langsung setelah menambahkan `and_expression` tanpa `prec.left` pada langkah 4b dan mendapatkan pesan error `Unresolved conflict for symbol sequence: _expr 'and' _expr • 'and' …`, serta menjalankan `tree-sitter test` pada `test/corpus/dasar.txt` tanpa koordinat hingga 6/6 pengujian lulus 100%. |
| Tugas 6 — Deteksi Syntax Error (`cek_error.py`) | Meminta pembuatan fungsi rekursif untuk mendeteksi file Python yang mengalami *syntax error* serta menemukan baris dan kolom pertama terjadinya `ERROR` atau `MISSING` node. | AI memberikan perintah PowerShell (`$kodeError = @' ...`) untuk membuat file secara otomatis; saat kode tersebut disalin langsung ke dalam editor `.py`, terjadi `SyntaxError: unterminated string literal` karena tercampurnya sintaks PowerShell dan Python. | Menjalankan `cek_error.py` langsung dan mendapati pesan `SyntaxError` di baris ke-3, kemudian memisahkan kode Python murni ke dalam `cek_error.py` dan mengujinya pada `uji_sintaks/` (`normal.py`, `rusak_titik_dua.py`, dan `rusak_kurung.py`) hingga berhasil mendeteksi 2 file error pada baris dan kolom yang tepat. |
